# 腐蚀板检测 / 诊断 ONNX 部署包 — 交付说明

## 包内容

```
交付版/
├── 腐蚀板检测onnx/        # SAE 异常检测（腐蚀板有无检测）
│   ├── sae_onnxruntime_inference.py   # 推理主程序（feature / voltage / voltage_dir 三种模式）
│   └── model/
│       ├── convert_scaler.py          # scaler 格式转换工具
│       ├── metadata.json              # 模型元信息（阈值、输入维度等）
│       └── scaler.json                # 标准化参数（json 版）
└── 腐蚀板诊断onnx/        # 多尺度 CNN 腐蚀等级诊断（4 级分类）
    ├── mscnn_onnxruntime_inference.py # 推理主程序（文件批处理 / stdin 实时流）
    ├── test_fs_256_classify.py        # 独立分类测试脚本
    ├── convert_mat_to_txt.py          # .mat 转 txt 工具
    ├── ONNX部署说明_多尺度CNN诊断.md   # 详细部署文档
    ├── 21.csv                         # 测试数据样例
    └── model/
        ├── convert_scaler.py
        ├── mscnn_metadata.json        # 模型元信息（类别名、维度等）
        └── scaler.json
```

## 运行环境

- Python 3.8+
- 依赖：`onnxruntime`、`numpy`、`pandas`、`joblib`（`.mat` 评估需另装 `scipy`）

```bash
pip install onnxruntime numpy pandas joblib
```

## 模型权重文件

为便于版本管理与授权控制，以下核心文件**不随本包发放，另行单独交付**：

- `model/sae_detector_model.onnx`、`model/sae_detector_scaler.pkl`（检测模型）
- `model/mscnn_model.onnx`、`model/mscnn_scaler.pkl`（诊断模型）

收到权重文件后，放入对应 `model/` 目录即可按部署文档正常运行。
在此之前运行推理脚本会提示缺少部署文件，属正常现象。

## 快速验证（权重文件就位后）

```bash
# 检测（特征模式）
python sae_onnxruntime_inference.py --mode feature --input 1.csv

# 诊断（文件批处理）
python mscnn_onnxruntime_inference.py --mode file --input_path data/1.txt
```

更多细节见《ONNX部署说明_多尺度CNN诊断.md》。
